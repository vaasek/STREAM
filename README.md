# Streamon

Свой сервер видеоконференций и прямых трансляций. Участники заходят из браузера: звонят друг другу, собираются в комнате, ведут эфир и пишут в чат. Управление пользователями, комнатами и журналом — в админке.

Сервер рассчитан на Linux. Медиа идёт через WebRTC (SFU mediasoup): потоки сходятся на вашей машине и не уходят во внешнее облако.

## Что умеет

- Конференция: у каждого камера, микрофон и показ экрана.
- Трансляция: ведущий в эфире, остальные смотрят. Ведущий может вывести зрителя в эфир.
- Стена экранов: экраны всех устройств в одной сетке. Уже идущие трансляции можно объединить в конференцию или на стену, не отключая источник.
- Приложение Android 6 и новее транслирует экран телефона или планшета на сервер и показывает стену.
- Звонок пользователю, который сейчас на сервере.
- Гостевой вход по ссылке, пароль комнаты, чат, поднятие руки.
- Админка: сводка, пользователи и роли, комнаты и трансляции, STUN/TURN, журнал действий.

Запись эфира в файл в эту версию не входит.

## Порты

| Назначение | Порт |
| --- | --- |
| Сайт, API, сигналинг | `8080/tcp` (или `443`, если перед сервером стоит Caddy) |
| Видео и звук | `40000–40199` UDP и TCP |

Камера и микрофон в браузере работают только на `localhost` или по HTTPS. Для доступа из сети нужен сертификат.

`ANNOUNCED_IP` в `.env` — это адрес, который клиенты подставляют в WebRTC. Укажите LAN- или публичный IP сервера и пробросьте диапазон UDP. Если оставить пустым, медиа откроется только на самой машине (`127.0.0.1`).

## Установка Docker на Linux

```bash
cp .env.example .env
# Отредактируйте ANNOUNCED_IP и при желании ADMIN_EMAIL / ADMIN_PASSWORD
docker compose up -d --build
```

Пароль первого администратора, если `ADMIN_PASSWORD` пустой, пишется в `data/initial-admin.txt`. Логин по умолчанию: `admin@streamon.local`.

HTTPS с именем в DNS:

```bash
# в .env: HOST=127.0.0.1 и DOMAIN=meet.example.com
docker compose --profile https up -d
```

Caddy сам получит сертификат Let's Encrypt. Сайт откроется на 443, медиа по-прежнему идёт на UDP `40000–40199` напрямую к Streamon.

Откройте порты, например так:

```bash
sudo ufw allow 8080/tcp
sudo ufw allow 40000:40199/udp
sudo ufw allow 40000:40199/tcp
```

При профиле `https` наружу достаточно `80`, `443` и диапазона медиа. `HOST=127.0.0.1` прячет порт `8080`.

## Установка на РЕД ОС

Нужна РЕД ОС 8. Официальный Node.js 22 собран на glibc 2.28, в РЕД ОС 7.3 его нет.

Скопируйте каталог на сервер. В `.env` в `ANNOUNCED_IP` укажите IP этой машины, не адрес компьютера, с которого велась разработка. Затем:

```bash
sudo bash install.sh
```

Скрипт через `dnf` ставит Python и компилятор, при необходимости скачивает Node.js 22 в `/usr/local`, собирает сайт, открывает в firewalld `8080/tcp` и `40000–40199` UDP/TCP и включает службу `streamon`.

Сайт для приложения: `http://IP-сервера:8080`. Камера и микрофон в браузере: `https://IP-сервера:8443`. Браузер один раз попросит подтвердить сертификат. Журнал: `journalctl --user -u streamon -f`. В приложении адрес сервера остаётся `http://IP:8080`.

## Установка без Docker на Debian или Ubuntu

Нужны Node.js 22+, Python 3 и компилятор (`build-essential`).

```bash
cp .env.example .env
# укажите ANNOUNCED_IP
bash install.sh          # сборка
sudo bash install.sh     # сборка и служба systemd
```

Самоподписанный сертификат, если нет домена:

Сервер сам выпускает сертификат для `ANNOUNCED_IP` и слушает HTTPS на порту `8443`. Порт `8080` остаётся обычным HTTP.

## Разработка

На Windows и macOS Docker с `network_mode: host` неудобен. Запускайте процессы напрямую:

```bash
npm install
npm run setup
npm run dev
```

Интерфейс: <http://127.0.0.1:5173>. API: порт `8080`. Для проверки видео на этой же машине `ANNOUNCED_IP` можно не задавать.

## Админка

После входа администратор видит ссылку «Админка».

- Обзор показывает, жив ли медиасервер, сколько людей в сети и не забыт ли `ANNOUNCED_IP`.
- Пользователи: создание, роль, отключение, смена пароля, удаление.
- Комнаты и трансляции: открыть, завершить, удалить.
- Настройки: имя сервера, регистрация, гости, лимиты, STUN и TURN.
- Журнал: входы, создание комнат, исключения, правки.

TURN заполняйте, только если клиенты из интернета не могут установить медиа напрямую. В одной локальной сети обычно хватает верного `ANNOUNCED_IP` и открытых UDP-портов.

## Как устроено

Браузер говорит с Node.js по HTTP и Socket.IO. Комната создаёт маршрутизатор mediasoup: каждый участник публикует свои дорожки и подписывается на чужие. Трансляция — та же комната, но публиковать может владелец и те, кого он вывел в эфир. Стена экранов показывает каждый экран отдельной плиткой. Объединение комнат передаёт уже опубликованное видео в выбранную комнату через тот же медиасервер. База SQLite лежит в `data/streamon.db`.

## Приложение Android

Каталог `android` открывается в Android Studio. Минимальная версия системы — Android 6. Сборка ставится на телефон или на эмулятор arm64 / x86_64.

1. На сервере в `.env` укажите `ANNOUNCED_IP` — IP машины в локальной сети, и откройте UDP/TCP `40000–40199`.
2. В приложении в поле сервера введите `http://IP:8080`. Адрес `localhost` с телефона указывает на сам телефон.
3. Войдите учётной записью сервера, создайте стену экранов или введите код комнаты.
4. Нажмите «Транслировать экран» и подтвердите запрос системы. Пока уведомление висит, экран уходит в комнату, даже если приложение свёрнуто.
5. На компьютере откройте ту же стену: плитки всех устройств стоят сеткой. Кнопка «Добавить трансляции» подмешивает уже идущие эфиры.

Приложение ходит на сервер по HTTP в локальной сети. Для доступа из интернета нужен HTTPS, как и браузеру.
